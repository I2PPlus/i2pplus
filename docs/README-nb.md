Dette er kildekoden for soft-forken av Java-implementasjonen av I2P.

Siste versjon: https://i2pplus.github.io/

## Installasjon

Se [INSTALL.md](docs/INSTALL.md) eller https://i2pplus.github.io/ for installasjonsinstruksjoner.

### Merknad om Windows-installeren

Med Java > 1.8 eller alternative distribusjoner (AdoptOpenJDK osv.) kan installasjonsprogrammet (.exe) feile med feilmeldingene "Java not found" eller "invalid/corrupt". Alternativ løsning: pakk ut install.jar fra exe-filen og kjør `java -jar install.jar` fra kommandolinjen.

## Bygge pakker fra kildekode

For å hente utviklingsgrenen fra kildekontrollen: https://github.com/I2PPlus/i2pplus

### Forutsetninger

- Java SDK 1.8.0 eller nyere
- Apache Ant 1.9.8 eller nyere
- Verktøyene xgettext, msgfmt og msgmerge installert fra GNU gettext-pakken
  via pakkehåndtereren din eller http://www.gnu.org/software/gettext/
- Byggemiljøet må bruke en UTF-8-locale.
- For bygg av Debian-pakker: `dpkg-deb`- og `fakeroot`-pakker (via pakkehåndtereren din)

### Ant-byggeprosess

På x86-systemer kjør følgende (dette bygger med IzPack4):

    ant pkg

På ikke-x86, bruk i stedet ett av følgende:

    ant installer-linux
    ant installer-freebsd
    ant installer-osx
    ant installer-windows

Hvis du vil bygge med IzPack5, last ned fra: http://izpack.org/downloads/ og
installer det, og kjør deretter følgende kommando(er):

    ant installer5-linux
    ant installer5-freebsd
    ant installer5-osx
    ant installer5-windows

For å bygge en usignert oppdatering for en eksisterende installasjon, kjør:

    ant updater

eller med Gradle:

    ./gradlew updater

Hvis du har problemer med å bygge en komplett installer (Java 14 og nyere kan generere byggfeil for izpack knyttet til pack200),
kan du bygge en komplett installasjonszip som kan pakkes ut og kjøres på stedet:

     ant zip-linux
     ant zip-freebsd
     ant zip-macos
     ant zip-windows

Kjør 'ant' uten argumenter for å se andre byggealternativer.

For å bygge et AppImage for Linux:
```bash
ant buildAppImage
```

Se [tools/appimage/README.md](tools/appimage/README.md) for detaljer.

For å bygge en selvstendig Debian-pakke for Debian/Ubuntu uten eksterne Jetty/Tomcat-avhengigheter:
```bash
ant buildDeb
```

Dette oppretter en selvstendig `.deb`-pakke som inneholder inkluderte Jetty- og Tomcat-biblioteker. Krever bare en OpenJDK-runtime (installeres automatisk via pakkehåndtereren).

For å kjøre i Docker, se [docker/README.md](docker/README.md)
