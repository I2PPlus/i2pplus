Bu, I2P-nin Java tətbiqinin soft-fork-unun mənbə kodudur.

Son buraxılış: https://i2pplus.github.io/

## Quraşdırma

Quraşdırma təlimatları üçün [INSTALL.md](docs/INSTALL.md) faylına və ya https://i2pplus.github.io/ səhifəsinə baxın.

### Windows quraşdırıcısı haqqında qeyd

Java > 1.8 və ya alternativ distributivlərdə (AdoptOpenJDK və s.) quraşdırıcı exe "Java not found" və ya "invalid/corrupt" xətaları ilə uğursuz ola bilər. Həll yolu: exe faylından install.jar arxivini çıxarın və əmr sətrində `java -jar install.jar` əmrini işə salın.

## Mənbə kodundan paketlərin qurulması

Tərtibat filialını mənbə idarəetməsindən əldə etmək üçün: https://github.com/I2PPlus/i2pplus

### İlkin tələblər

- Java SDK 1.8.0 və ya yuxarı versiya
- Apache Ant 1.9.8 və ya yuxarı versiya
- GNU gettext paketindən gələn xgettext, msgfmt və msgmerge vasitələrinin paket meneceriniz
  vasitəsilə və ya http://www.gnu.org/software/gettext/ ünvanından quraşdırılması
- Qurulma mühiti UTF-8 lokalından istifadə etməlidir.
- Debian paketlərinin qurulması üçün: `dpkg-deb` və `fakeroot` paketləri (paket meneceriniz vasitəsilə)

### Ant ilə qurulma prosesi

x86 sistemlərində aşağıdakını işə salın (bu, IzPack4 ilə qurulacaq):

    ant pkg

x86 olmayan sistemlərdə bunun əvəzinə aşağıdakılardan birini istifadə edin:

    ant installer-linux
    ant installer-freebsd
    ant installer-osx
    ant installer-windows

IzPack5 ilə qurmaq istəyirsinizsə, http://izpack.org/downloads/ ünvanından endirin,
sonra onu quraşdırın və aşağıdakı əmri(-əmrləri) işə salın:

    ant installer5-linux
    ant installer5-freebsd
    ant installer5-osx
    ant installer5-windows

Mövcud quraşdırma üçün imzalanmamış yeniləmə qurmaq üçün aşağıdakını işə salın:

    ant updater

və ya Gradle ilə:

    ./gradlew updater

Tam quraşdırıcı qurarkən problemləriniz varsa (Java14 və sonrakı versiyalar izpack üçün pack200
ilə əlaqəli qurulma xətaları yarada bilər), arxivini çıxararaq birbaşa işə sala biləcəyiniz
tam quraşdırma zip faylı qura bilərsiniz:

     ant zip-linux
     ant zip-freebsd
     ant zip-macos
     ant zip-windows

Digər qurulma seçimlərini görmək üçün 'ant' əmrini heç bir arqumentsiz işə salın.

Linux üçün AppImage qurmaq üçün:
```bash
ant buildAppImage
```

Təfərrüatlar üçün [tools/appimage/README.md](tools/appimage/README.md) faylına baxın.

Xarici Jetty/Tomcat asılılıqları olmadan Debian/Ubuntu üçün müstəqil Debian paketi qurmaq üçün:
```bash
ant buildDeb
```

Bu, daxili Jetty və Tomcat kitabxanalarını ehtiva edən müstəqil `.deb` paketi yaradır. Yalnız OpenJDK icra mühiti tələb olunur (paket menecerinin köməyi ilə avtomatik quraşdırılır).

Docker-da işə salmaq üçün [docker/README.md](docker/README.md) faylına baxın
