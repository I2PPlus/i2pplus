# I2P+ Source Directory Guide

A quick reference to the I2P+ source tree layout.

| Directory                                                               | Description                                                        | README                                                               |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------- |
| `apps`                                                                  | Applications and clients that ship with I2P.                       | [README.md](../apps/README.md)                                       |
| `apps/addressbook`                                                      | Headless addressbook management code.                              | [README.md](../apps/addressbook/README.md)                           |
| `apps/apparmor`                                                         | AppArmor ruleset.                                                  |                                                                      |
| `apps/BOB`                                                              | BOB service code.                                                  |                                                                      |
| `apps/desktopgui`                                                       | System tray application.                                           | [README.md](../apps/desktopgui/README.md)                            |
| `apps/i2psnark`                                                         | Torrent client component in the web console.                       | [README.md](../apps/i2psnark/README.md)                              |
| `apps/i2ptunnel`                                                        | Hidden Service Manager and its GUI in the web console.             | [README.md](../apps/i2ptunnel/README.md)                             |
| `apps/imagegen`                                                         | Image generator webapp.                                            | [README.md](../apps/imagegen/README.md)                              |
| `apps/jetty`                                                            | Jetty webserver code.                                              | [README.md](../apps/jetty/README.md)                                 |
| `apps/jrobin`                                                           | Graph package for the console.                                     | [README.md](../apps/jrobin/README.md)                                |
| `apps/ministreaming`                                                    | Streaming (TCP-like socket) interface.                             | [README.md](../apps/ministreaming/README.md)                         |
| `apps/routerconsole`                                                    | Router console code.                                               | [README.md](../apps/routerconsole/README.md)                         |
| `apps/routerconsole/java/src/net/i2p/router/news`                       | News feed subsystem.                                               |                                                                      |
| `apps/routerconsole/java/src/net/i2p/router/update`                     | Automatic update subsystem.                                        |                                                                      |
| `apps/routerconsole/java/src/net/i2p/router/web`                        | Console Java code, including plugin support.                       |                                                                      |
| `apps/routerconsole/jsp`                                                | JSPs for the console.                                              |                                                                      |
| `apps/sam`                                                              | SAM service.                                                       | [README.md](../apps/sam/README.md)                                   |
| `apps/streaming`                                                        | Streaming (TCP-like socket) implementation.                        | [README.md](../apps/streaming/README.md)                             |
| `apps/susidns`                                                          | Addressbook component in the web console.                          | [README.md](../apps/susidns/README.md)                               |
| `apps/susimail`                                                         | Mail client component in the web console.                          | [README.md](../apps/susimail/README.md)                              |
| `apps/systray`                                                          | Legacy system tray application (removed) and related utilities.    | [README.md](../apps/systray/README.md)                               |
| `installer`                                                             | Installer code.                                                    | [README.md](../installer/README.md)                                  |
| `installer/lib/izpack`                                                  | Installer libraries.                                               | [README.md](../installer/lib/izpack/README.md)                       |
| `installer/lib/jbigi`                                                   | jbigi and jcpuid DLLs.                                             | [README.md](../installer/lib/jbigi/README.md)                        |
| `installer/lib/launch4j`                                                | Windows jar-to-exe binary.                                         | [README.md](../installer/lib/launch4j/README.md)                     |
| `installer/lib/wrapper`                                                 | Wrapper binaries and libraries.                                    | [README.md](../installer/lib/wrapper/README.md)                      |
| `installer/resources`                                                   | Static files bundled with I2P.                                     | [README.md](../installer/resources/README.md)                        |
| `core/java`                                                             | Common core code used by both the router and apps.                 | [README.md](../core/README.md)                                       |
| `core/java/src/net/i2p`                                                 | Core library packages under `net.i2p`.                             | [README.md](../core/java/src/net/i2p/README.md)                      |
| `core/java/src/net/i2p/app`                                             | App interface code.                                                |                                                                      |
| `core/java/src/net/i2p/client`                                          | Low-level client I2CP interface (I2PClient, I2PSession, etc.).     | [README.md](../core/java/src/net/i2p/client/README.md)               |
| `core/java/src/net/i2p/client/impl`                                     | Client-side I2CP implementation.                                   | [README.md](../core/java/src/net/i2p/client/impl/README.md)          |
| `core/java/src/net/i2p/client/naming`                                   | Addressbook interfaces and base implementation.                    |                                                                      |
| `core/java/src/net/i2p/crypto`                                          | Most of the crypto code.                                           | [README.md](../core/java/src/net/i2p/crypto/README.md)               |
| `core/java/src/net/i2p/data`                                            | Common data structures and data-related utilities.                 | [README.md](../core/java/src/net/i2p/data/README.md)                 |
| `core/java/src/net/i2p/internal`                                        | Internal socketless I2CP connections.                              |                                                                      |
| `core/java/src/net/i2p/kademlia`                                        | Base Kademlia implementation used by the router and i2psnark.      | [README.md](../core/java/src/net/i2p/kademlia/README.md)             |
| `core/java/src/net/i2p/socks`                                           | SOCKS client implementation.                                       | [README.md](../core/java/src/net/i2p/socks/README.md)                |
| `core/java/src/net/i2p/stat`                                            | Statistics subsystem.                                              |                                                                      |
| `core/java/src/net/i2p/time`                                            | Internal time representation.                                      |                                                                      |
| `core/java/src/net/i2p/update`                                          | Parts of the update code.                                          |                                                                      |
| `core/java/src/net/i2p/util`                                            | Utility code (Log, FileUtil, EepGet, HexDump, etc.).               | [README.md](../core/java/src/net/i2p/util/README.md)                 |
| `router/java`                                                           | I2P router code.                                                   | [README.md](../router/README.md)                                     |
| `router/java/src/net/i2p`                                               | Router-side `net.i2p` packages.                                    | [README.md](../router/java/src/net/i2p/README.md)                    |
| `router/java/src/net/i2p/data/i2np`                                     | I2NP code, the inner protocol for I2P.                             | [README.md](../router/java/src/net/i2p/data/i2np/README.md)          |
| `router/java/src/net/i2p/data/router`                                   | Router data structures such as RouterInfo.                         | [README.md](../router/java/src/net/i2p/data/router/README.md)        |
| `router/java/src/net/i2p/router`                                        | Router application core.                                           | [README.md](../router/java/src/net/i2p/router/README.md)             |
| `router/java/src/net/i2p/router/client`                                 | Router-side I2CP implementation.                                   | [README.md](../router/java/src/net/i2p/router/client/README.md)      |
| `router/java/src/net/i2p/router/crypto`                                 | Router crypto not needed in the core library.                      | [README.md](../router/java/src/net/i2p/router/crypto/README.md)      |
| `router/java/src/net/i2p/router/dummy`                                  | Dummy implementations of subsystems for testing.                   |                                                                      |
| `router/java/src/net/i2p/router/message`                                | Garlic message creation and parsing.                               | [README.md](../router/java/src/net/i2p/router/message/README.md)     |
| `router/java/src/net/i2p/router/networkdb`                              | NetDB coordination and DHT.                                        | [README.md](../router/java/src/net/i2p/router/networkdb/README.md)   |
| `router/java/src/net/i2p/router/networkdb/kademlia`                     | DHT (Kademlia) code.                                               |                                                                      |
| `router/java/src/net/i2p/router/networkdb/reseed`                       | Reseed code.                                                       |                                                                      |
| `router/java/src/net/i2p/router/peermanager`                            | Peer profile tracking and storage.                                 | [README.md](../router/java/src/net/i2p/router/peermanager/README.md) |
| `router/java/src/net/i2p/router/startup`                                | Startup sequence code.                                             | [README.md](../router/java/src/net/i2p/router/startup/README.md)     |
| `router/java/src/net/i2p/router/tasks`                                  | Small router helpers, run periodically.                            | [README.md](../router/java/src/net/i2p/router/tasks/README.md)       |
| `router/java/src/net/i2p/router/transport`                              | Transport implementation code (NTCP, SSU).                         | [README.md](../router/java/src/net/i2p/router/transport/README.md)   |
| `router/java/src/net/i2p/router/transport/crypto`                       | Transport crypto (DH).                                             |                                                                      |
| `router/java/src/net/i2p/router/tunnel`                                 | Tunnel implementation code.                                        | [README.md](../router/java/src/net/i2p/router/tunnel/README.md)      |
| `router/java/src/net/i2p/router/util`                                   | Router utilities.                                                  |                                                                      |
