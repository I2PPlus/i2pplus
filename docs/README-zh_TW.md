這是I2P之Java實作軟分岔（soft-fork）的原始碼。

最新版本：https://i2pplus.github.io/

## 安裝

安裝說明請參閱[INSTALL.md](INSTALL.md)或https://i2pplus.github.io/。

### Windows安裝程式注意事項

使用Java > 1.8或其他發行版（例如AdoptOpenJDK等）時，安裝程式exe可能會出現「Java not found」或「invalid/corrupt」錯誤。解決方法：從exe中解壓出install.jar，並在命令列執行`java -jar install.jar`。

## 從原始碼建置套件

若要取得開發分支原始碼：https://github.com/I2PPlus/i2pplus

### 先決條件

- Java SDK 1.8.0或更新版本
- Apache Ant 1.9.8或更新版本
- 透過套件管理員或http://www.gnu.org/software/gettext/安裝GNU gettext套件中的xgettext、msgfmt與msgmerge工具
- 建置環境必須使用UTF-8語系。
- 若要建置Debian套件：需要`dpkg-deb`與`fakeroot`套件（透過套件管理員安裝）

### Ant建置流程

在x86系統上執行以下指令（將使用IzPack4建置）：

    ant pkg

在非x86系統上，請改用以下其中一項：

    ant installer-linux
    ant installer-freebsd
    ant installer-osx
    ant installer-windows

若要以IzPack5建置，請先從http://izpack.org/downloads/下載並安裝，然後執行以下其中一項指令：

    ant installer5-linux
    ant installer5-freebsd
    ant installer5-osx
    ant installer5-windows

若要為現有安裝建立未簽章的更新檔，請執行：

    ant updater

或使用Gradle：

    ./gradlew updater

若在建立完整安裝程式時遇到問題（Java14與更新版本可能產生與izpack的pack200相關的建置錯誤），可以改為建立完整的安裝zip檔，解壓縮後即可就地執行：

     ant zip-linux
     ant zip-freebsd
     ant zip-macos
     ant zip-windows

不帶參數執行「ant」可查看其他建置選項。

若要為Linux建立AppImage：
```bash
ant buildAppImage
```

詳情請參閱[tools/appimage/README.md](../tools/appimage/README.md)。

若要為Debian/Ubuntu建立不依賴外部Jetty/Tomcat的自含式Debian套件：
```bash
ant buildDeb
```

這會產生自含式的`.deb`套件，其中包含內建的Jetty與Tomcat函式庫。僅需要OpenJDK執行環境（會透過套件管理員自動安裝）。

若要在Docker中執行，請參閱[docker/README.md](../docker/README.md)
