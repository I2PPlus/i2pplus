The netdb's data. {@code RouterInfoTest} covers loading a router info from its file, storing it back, and the cache in between, with a signature verification. {@code RouterIdentityTest} covers what an identity refuses: a null certificate, public key, or signing key, and the hash it calculates from its own bytes. {@code RouterAddressTest} covers the transport options, the cost bounds that throw, and the wrapped {@code toString} a router info is written with. Run by {@code ant test} in {@code router/java}.
