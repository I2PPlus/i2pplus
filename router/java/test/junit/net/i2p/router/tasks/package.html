The periodic jobs and events in net.i2p.router.tasks, tested as decisions. {@code CoalesceStatsEventTest} covers the stats aggregation event: that construction creates the rate stats it reports through, and that a full pass completes and populates the coalesced rates. {@code RouterWatchdogLivelinessTest} covers the watchdog's "a job has been running too long" decision, the one that writes a CRIT line, dumps every thread, and with the wrapper present can force a restart - so a false hit on an idle, healthy queue is a real defect, not a cosmetic one. Run by ant test in router/java.
