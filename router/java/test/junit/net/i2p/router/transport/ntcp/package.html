NTCP and NTCP2, tested as decisions rather than through a socket. The event pumper: what it does when a connect fails, the pumper's run/stop decision, its rate accounting, and its write pool and write path. The connection: the backlog decision, the establishment RTT, the read pause, the router-info decision, and the memory a failsafe close leaves behind. NTCP2's wire format: frame packing, the payload block, the post-quantum handshake's sizes, and the staging of its first message. The transport: the ban-check throttle, the inbound flood decision, and the address, bid, reachability and setup decisions. Run by ant test in router/java.
