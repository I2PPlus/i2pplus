The decisions made while the router comes up. {@code ClientAppConfigTest} covers the config line parsed out of clients.config: the constructors and their fields, a null argument, a zero or negative start delay, and equality and hashing. {@code RouterAppManagerRowsTest} covers the row merge for the console's clients page - a tracked app wins over its registered twin, an untracked registration gets a "Registered" row - and the state-to-dot-colour mapping. {@code WorkingDirTest} covers the file helpers: copying with the timestamp preserved, overwriting an existing file, a missing source, and the XML migration that rewrites paths in jetty.xml. Run by ant test in router/java.
