Router utility classes: CoDel active queue management, time-decaying collections, a diagnostics ring buffer, CIDR matching, and password management. Not for use by apps, clients or plugins.

The main classes are {@link net.i2p.router.util.CoDelBlockingQueue}, {@link net.i2p.router.util.CoDelPriorityBlockingQueue}, {@link net.i2p.router.util.DecayingBloomFilter}, {@link net.i2p.router.util.DecayingHashSet}, {@link net.i2p.router.util.EventLog}, {@link net.i2p.router.util.MaskedIPSet} and {@link net.i2p.router.util.RouterPasswordManager}.

See also: RFC 8289 (CoDel).
