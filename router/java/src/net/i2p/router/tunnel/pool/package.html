Tunnel pool management, creation, and peer selection for I2P's anonymous routing system.

This package provides:

  • TunnelPool - Inbound/outbound tunnel pool lifecycle management
  • BuildRequestor - Build message creation and throttling
  • BuildExecutor - Coordinate and dispatch tunnel build requests
  • BuildMessageProcessor - Process incoming tunnel build messages
  • TestJob - Tunnel test and validation
  • ExpireJob - Tunnel expiration and cleanup
  • TunnelPeerSelector - Intelligent peer selection for tunnel paths
  • RequestThrottler - Build request rate limiting
  • PooledTunnelCreatorConfig - Tunnel creation configuration
