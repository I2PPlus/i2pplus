Tunnel messages and the tunnel layer: the {@link net.i2p.router.TunnelManagerFacade}, tunnel build request and reply processing, and the inbound and outbound tunnel structures.

{@link net.i2p.router.tunnel.TunnelDispatcher} routes each message to the processor for the router's role in the tunnel - inbound gateway or endpoint, outbound gateway or endpoint, or middle hop. Not for use by apps, clients or plugins.
