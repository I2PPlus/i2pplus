• د پیل لپاره
    کله چې I2P+ تازه پیل کړی، د فعالو peerونو شمېر چې په پیر کې د سایډ بار په برخه کې ښکاره دی، باید د راتلونکو دقیقو په لړ کې د زیاتېدو په حال کې شی، او ستا د محلی تاریب چې ورځې شوی کلآینټونه نومیږی، چې په د سروس ټونلونوبرخه کې لیست شوی، او ممکن نور کلآینټونه او سرورونه هم وی، بسته پرې چې I2P څنګه تنظیم شوی. دا محلی تاریبونه د نټورک په مختلفو پورټونو کې د سروسونو اتصالونه ورکوی، چې په اجازه BitTorrent، میل، ویب پروکسی او نور سروسونه کار وکړی. ستا د نټورک ډیټابیس ټول هغه peerونه ښیی چې په نټورک کې په محلی توګه پېژندل شوی. ستا له peerونو څخه موجود اړیکې هم کولی شې، د peerونو د کاروونې پروفایلونه وګورې او فعال ټونلونه وګورې.
  • په نټورک کې ادغامول
    لومړی ځل چې I2P+ پیل کړې، ممکن څو دقیقې ونیسې ترڅو په نټورک کې پیل (ادغام) شی او نور peerونه پیدا کړې ترڅو ستا ادغام غوره شی، نو مهربانی وکړئ صبر وکړئ. کله چې ستا محلی تاریبو کنار کې د سایډ بار په د سروس ټونلونو برخه کې شنه ستورې ښکاره شی، نو په I2P سره ډېری څه کارونه کولای شې، او لاندې څو یې راښودل کېږی.
  • د نټورک حالت
    کله چې I2P+ وخت لری ترڅو ستا د نټورک اړیکې ازموینه وکړی، د نټورک د حالت ښیونکی په سایډ بار کې باید «OK» وښیی. که حالت «Firewalled» وښیی، I2P+ به یوازې کار وکړی خو د نټورک کاروونې غوره نه ده، او ستا د نټورک ته د باندویډټ د ورکولو وړتیا به محدوده وی. د غوره کاروونې لپاره، خپل پورټ د I2P+ له پاتې د د I2P+ بهرنی پورټ د فایروال او له ISP لخوا ورکړ شوی راوټر کې د خلاصولو په اړه سوښ کړئ. د حالت پیغامونو په اړه نور معلومات د کاروونکی پرتلې د مرستې پاڼهکې شته.
  • د پتې کتاب سابسکریپشنونه
    ترڅو I2P+ په خپله خپله د .i2p هاست نیمونه حل کړی، اصل پر هغو سروسونو سابسکریپشنونو پورې دی چې د پېژندل شویو کوربو لپاره DNS ژباړونکی وړکوی. که ته I2P+ نصب کړی نه دې خو له I2P څخه نوې کول کې، نو به د کافی د پتې کتاب سابسکریپشنونه تنظیم شوی وی؛ د نصب وروسته، ستا پتې کتاب باید په خپله خپله د نټورک د فعالو سروسونو د هاست نیمونو په ډکولو کې وی. که له I2P څخه نوې کولې، د د پتې کتاب سابسکریپشنونو برخه په ډېره کې پوښت شوې پوښتنو کې وګورئ ترڅو د نورو سابسکریپشنونو د زیاتولو په اړه مرسته واخلئ.
  • د براوزر ترتیبات
    ترڅو په نټورک کې ویب پاڼو ته وګرځې، باید خپل براوزر د پورټ 4444 کې تنظیم شوی ابدۍ HTTP پروکسی د کارولو لپاره تنظیم کړې، چې یو outproxy هم ورکوی چې د clearnet پاڼو ته په ناڅرګنده توګه وګرځې. په د مرستې د د Firefox د تنظیم لنډه لارښود د ترتیباتو په برخه کې ورکړل شوی، یا لاندې برخه وګورئ ترڅو د څو براوزرونو د تنظیم لارښود ته لنک واخلئ. کله چې خپل براوزر او د پتې کتاب سابسکریپشنونه تنظیم کړې، notbob.i2p د نټورک د منځنیو محتیاو د لپاره یو ښه پاڼه ده.

په I2P کې سروسونه

  • ناڅرګند او عامه انټرنیټ وګرځنه
    په I2P کې کولای شې د I2P هټې («eepsites») ویب پاڼو ته لاسرسی واخلې، یا له I2P سره تړ په شامل شوی ویب پروکسی (outproxy) له لارې په عادی انټرنیټ په ناڅرګنده توګه وګرځې. خپل براوزر ترتیب کړئ چې دا HTTP پروکسی د 127.0.0.1 پورټ 4444په کارولو سره وکاروئ، بیا د http://سره یو پټی سروس یا یوه عادی نه کوږ شوې پته ته وګرځې. ترڅو د عادی انټرنیټ له لارې د outproxy لاسرسی غیر فعال یا بدل کړې، د false.i2p یا purokishi.i2p لپاره د outproxy مدخل، د outproxy په سمولړ صفحه کې د HTTP پروکسی د کلآینټ د ټونل په ټونل مدیرکې.
  • ناڅرګند میل
    د Postman د I2P پر بنسټ د میل سیسټم له د I2P پخپل میل کلآینټ (Susimail) یا هر یوه عادی میل کلآینټ له لارې لاسرسی لری. یو میل دروازه د عادی انټرنیټ د پتوڼو له میل نیولو اجازه ورکوی؛ ستا @mail.i2p پته هم @i2pmail.orgله لارې اړیکه لرې. د حساب لپاره hq.postman.i2pته لاړ شو.
  • ناڅرګند د فایلونو لېږل
    I2PSnark په I2P کې جوړ شوی او ناڅرګند، کوږ شوی BitTorrent لېږونه وړاندیزوی. په بدیل توګه، BiglyBT (د Azureus/Vuze وارث) شته، یو BitTorrent کلآینټ چې له I2P له لارې torrentونه مننه کوی، او XD، یو په Go لیکل شوی، د I2P لپاره ځانګړی BitTorrent کلآینټ. نور سروسونه په شاملېدو پولو د براوزر پر بنسټ د فایلونو کوربه کول دی، لکه cake.i2p او fs.i2p.
  • ناڅرګند چټ
    خپل IRC کلآینټ (د بیلګې مثال، HexChat) پیل کړې او په سرور سره وصل شې چې په 127.0.0.1 پورټ 6668کې ده. ستا په IRC کلآینټ کې د پروکسی تنظیم کولو ته اړتیا نشته؛ I2P درته یو محلی IRC ټونل ورکوی (چې په خپل IRC کلآینټ کې د IRC سرور یا لرونکی کوربه په توګه تنظیم شوی). هغه ځای ته #saltr او #i2p-dev یوازې څو هغو مجله کانالونو څخه دی چې کولای شې ورسره یونیږې. همداڅه یو د پلیټفارم له مخې د I2P پر بنسټ د خپل لحظه پیغام لېږلو اپلیکیشن شته چې په Githubکې دی.
  • ناڅرګند او کوږ شوی ویب کوربه کول
    I2P له خپل ځان سره یو ویب سرور راوړی چې د I2P نټورک کې ستا خپله ویب پاڼه کوربه کړې: د Jetty یوه بېلتونه چې په http://127.0.0.1:7658/کې اورېږی. د د I2P ویب سرورسمبالوندی ټونل پیل کړې وروسته، ستا پاڼه د نورو لپاره لیدل (خو نه موندل کېدای) به شی. د خپلې پاڼې د تنظیم او د .i2p ډومین د راجستولو لپاره لارښودونه په د مرستې برخهکې شته.
  • د I2P پلاګینونه
    د zzz پلاګینونو پاڼه ته ولاړ شو چې څو پلاګینونه سمدستی ښکته یې کړې. که ته پراختیوال یې، نو یو فریم ورک چې د خپلو پلاګینونو د لیکلو لپاره د ژبې له مخې خوندی وی ورکړل کېږی.

د پراختیوالیو او مرستندوی په اړه معلومات

  • تېروتنې راپورول
    د تېروتنې د راپورولو لپاره، مهربانی وکړئ په github.com/I2PPlus/i2pplus/issuesکې یو ټکیټ داخل کړئ. د پراختیوالیو په اړه بېښه ونو لپاره، مهربانی وکړئ د zzz د پراختیوالیو پورمونه یا د د پراختیوالیو کانال (#i2p-dev) د I2P د IRC نټورک کې وګورې.
  • په I2P کې جوړول
    که ته پراختیوال یې، کولای شې خپلې I2P اپلیکیشنونه ولیکې، یا د I2P نټورک له استفې وړتیا غوره کړې. د UDP په څخه TCP پروټوکولونه د موخه وړکویدی، او د وخت لېږلوهم شته. موږ د Java APIته بشپړ لاسرسی هم ورکوو، او د I2P بنسټیز کتابونه په Apache Maven ریپازیټریکې کوربه شوی. پراختیوالی کولای شې د Github (I2P) یا Github (I2P+) د سرچینې کوډ ګورو او د جوړولو اوسنۍ حالت، د Travis (I2P) د دوامدارې شمولیت پلیټفارم له لارې یا د Gitlab (I2P+) له لارې وګورې. Java SDK او Apache Ant ته اړتیا ده چې له سرچینې کوډ څخه جوړ کړې.
  • ګډون وکړې!
    I2P په بنسټیز توګه د ټولنې د غړونو د خپل ارادې او بې له مالیې ګډون له لارې جوړ او ساتل کېږی. د دې ډول ګډون په اړه نور معلومات په د رضاکارانو پاڼه کې، د رسمی ویب پاڼه په اړه شته.
  • I2P+
    د I2P+ په اړه نور skank.i2p معلومات لپاره، مهربانی وکړئ i2pplus.github.ioته ولاړ شو، یا د I2P د IRC نټورک په #saltR کانال ته ورسره ونیسې. د I2P+ لپاره پیچونه منل کېږی؛ مهربانی وکړئ د غوښتنې د لرې کولو پېټې له لارې ولېږئ Gitlabله لارې.
