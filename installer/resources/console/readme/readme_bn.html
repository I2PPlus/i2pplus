• শুরু করা
    আপনি যদি এইমাত্র I2P+ শুরু করেন, সাইডবারে Peers বিভাগের নিচে নির্দেশিত Active Peers এর সংখ্যা কয়েক মিনিটের মধ্যে বাড়তে শুরু করবে, এবং আপনি Service Tunnels বিভাগের নিচে Shared Clients নামে একটি Local Destination দেখতে পাবেন, এবং I2P কীভাবে কনফিগার করা হয়েছে তার উপর নির্ভর করে অন্যান্য ক্লায়েন্ট এবং সার্ভারও দেখতে পাবেন। এই Local Destinations বিভিন্ন পোর্টে সার্ভিসগুলোতে সংযোগ প্রদান করে, যা BitTorrent, ইমেইল, ওয়েব প্রক্সি এবং অন্যান্য সার্ভিসগুলোকে কার্যকর করে তোলে। আপনার Network Database নেটওয়ার্কের সমস্ত স্থানীয়ভাবে পরিচিত পিয়ার নির্দেশ করে। আপনি বিদ্যমান পিয়ার সংযোগগুলো মনিটর করতে পারেন, পিয়ার পারফরম্যান্স প্রোফাইলগুলো পর্যালোচনা করতে পারেন এবং সক্রিয় টানেলগুলো এবং তাদের স্থিতি দেখতে পারেন।
  • নেটওয়ার্ক ইন্টিগ্রেশন
    প্রথমবার I2P+ শুরু করলে নেটওয়ার্কে বুটস্ট্র্যাপ (ইন্টিগ্রেট) হতে এবং আপনার ইন্টিগ্রেশন অপ্টিমাইজ করতে অতিরিক্ত পিয়ার খুঁজে পেতে কয়েক মিনিট সময় লাগতে পারে, তাই অনুগ্রহ করে ধৈর্য ধরুন। সাইডবারে Service Tunnels এর নিচে আপনার Local Destinations এর পাশে সবুজ তারকা প্রদর্শিত হলে, I2P দিয়ে আপনি বিভিন্ন কাজ করতে পারেন, এবং নিচে আমরা তাদের কিছু সম্পর্কে আপনাকে পরিচিত করিয়ে দিচ্ছি।
  • নেটওয়ার্ক স্থিতি
    I2P+ আপনার নেটওয়ার্ক সংযোগ পরীক্ষা করার পর, সাইডবারে নেটওয়ার্ক স্থিতি নির্দেশক আদর্শভাবে "OK" নির্দেশ করবে। স্থিতি "Firewalled" নির্দেশ করলে, I2P+ এখনও কাজ করবে যদিও নেটওয়ার্ক পারফরম্যান্স সর্বোত্তম হবে না, এবং নেটওয়ার্কে ব্যান্ডউইথ অবদান রাখার আপনার সক্ষমতা বাধাগ্রস্ত হবে। সর্বোত্তম পারফরম্যান্সের জন্য, অনুগ্রহ করে আপনার ফায়ারওয়াল এবং ISP প্রদত্ত রাউটারে আপনার বহিরাগত I2P+ পোর্ট খোলার কথা বিবেচনা করুন। স্থিতি বার্তা সম্পর্কে আরও তথ্য ইউজার ইন্টারফেস সাহায্য পৃষ্ঠায় পাওয়া যায়।
  • অ্যাড্রেসবুক সাবস্ক্রিপশন
    I2P+ যেন .i2p হোস্টনেম স্বয়ংক্রিয়ভাবে সমাধান করতে পারে, তার জন্য প্রাথমিকভাবে এমন সার্ভিসগুলোর সাবস্ক্রিপশনের উপর নির্ভর করে যা পরিচিত হোস্টের জন্য DNS অনুবাদ প্রদান করে। আপনি যদি I2P থেকে আপগ্রেড না করে I2P+ ইনস্টল করে থাকেন, তাহলে আপনার ইতিমধ্যে পর্যাপ্ত অ্যাড্রেসবুক সাবস্ক্রিপশন কনফিগার করা থাকবে; ইনস্টলেশনের পর, আপনার অ্যাড্রেসবুক নেটওয়ার্কে সক্রিয় সার্ভিসগুলোর হোস্টনেম দিয়ে কোনো হস্তক্ষেপ ছাড়াই পূর্ণ হওয়া উচিত। আপনি যদি I2P থেকে আপগ্রেড করে থাকেন, অতিরিক্ত সাবস্ক্রিপশন যোগ করার সাহায্যের জন্য FAQ তে অ্যাড্রেসবুক সাবস্ক্রিপশন বিভাগ দেখুন।
  • ব্রাউজার কনফিগারেশন
    নেটওয়ার্কে ওয়েবসাইট ব্রাউজ করতে, আপনাকে আপনার ব্রাউজারকে 4444 পোর্টে কনফিগার করা ডিফল্ট HTTP প্রক্সি ব্যবহার করার জন্য সেটআপ করতে হবে, যা একটি outproxy ও প্রদান করে যা ক্লিয়ারনেট সাইটগুলো বেনামীভাবে ব্রাউজ করার অনুমতি দেয়। সাহায্য বিভাগের Configuration পৃষ্ঠায় একটি Firefox কনফিগার করার মিনি-গাইড দেওয়া আছে, অথবা বহু-ব্রাউজার সেটআপ গাইডের লিঙ্কের জন্য নিচের বিভাগ দেখুন। আপনার ব্রাউজার এবং অ্যাড্রেসবুক সাবস্ক্রিপশন কনফিগার করার পর, notbob.i2p নেটওয়ার্কে কন্টেন্ট আবিষ্কার করার জন্য একটি চমৎকার সাইট।

I2P-তে সার্ভিসসমূহ

  • অদৃশ্য ইন্টারনেট ও পাবলিক ওয়েব ব্রাউজিং
    I2P-তে আপনি I2P-হোস্টেড ওয়েবসাইট ("eepsites") অ্যাক্সেস করতে পারেন অথবা I2P-এর অন্তর্নির্মিত ওয়েব প্রক্সি (outproxy) এর মাধ্যমে স্বাভাবিক ওয়েব বেনামীভাবে ব্রাউজ করতে পারেন। HTTP প্রক্সি 127.0.0.1 port 4444 ব্যবহার করার জন্য আপনার ব্রাউজার কনফিগার করুন, তারপর একটি গোপন সার্ভিস ওয়েবসাইট বা স্বাভাবিক, এনক্রিপ্ট না করা http:// ঠিকানায় ব্রাউজ করুন। স্বাভাবিক ইন্টারনেটে outproxy অ্যাক্সেস নিষ্ক্রিয় বা পরিবর্তন করতে, Tunnel Manager-এ HTTP প্রক্সি ক্লায়েন্ট টানেলের এডিট পৃষ্ঠায় Outproxies বিভাগের নিচে false.i2p বা purokishi.i2p এর outproxy এন্ট্রি সরান বা পরিবর্তন করুন।
  • বেনামী ইমেইল
    Postman-এর I2P-ভিত্তিক মেইল সিস্টেমে I2P-এর অন্তর্নির্মিত মেইল ক্লায়েন্ট (Susimail) বা যেকোনো স্ট্যান্ডার্ড মেইল ক্লায়েন্টের মাধ্যমে প্রবেশ করা যায়। একটি মেইল গেটওয়ে স্বাভাবিক ইন্টারনেট ঠিকানা থেকে মেইল গ্রহণ করার সুবিধা দেয়; আপনার @mail.i2p ঠিকানা @i2pmail.org এর মাধ্যমেও যোগাযোগ করা যায়। অ্যাকাউন্টের জন্য hq.postman.i2p পরিদর্শন করুন।
  • বেনামী ফাইল ট্রান্সফার
    I2PSnark I2P-তে একীভূত, বেনামী, এনক্রিপ্টেড BitTorrent ট্রান্সফার প্রদান করে। বিকল্পভাবে, BiglyBT (Azureus/Vuze-এর উত্তরসূরি), একটি BitTorrent ক্লায়েন্ট যা I2P-তে টরেন্টিং সমর্থন করে, এবং XD, go-তে লেখা একটি শুধুমাত্র I2P BitTorrent ক্লায়েন্ট আছে। অতিরিক্ত সার্ভিসগুলোর মধ্যে রয়েছে ব্রাউজার-ভিত্তিক ফাইল হোস্টিং যেমন cake.i2p এবং fs.i2p।
  • বেনামী চ্যাট
    আপনার IRC ক্লায়েন্ট চালু করুন (যেমন HexChat) এবং 127.0.0.1 port 6668-এ সার্ভারে সংযোগ করুন। আপনার IRC ক্লায়েন্টে প্রক্সি কনফিগার করার প্রয়োজন নেই; I2P আপনাকে একটি স্থানীয় IRC টানেল প্রদান করে (আপনার IRC ক্লায়েন্টে একটি IRC সার্ভার বা দূরবর্তী হোস্ট হিসেবে কনফিগার করা)। এখানে পৌঁছানোর পর, #saltr এবং #i2p-dev উপলব্ধ চ্যানেলগুলোর মধ্যে মাত্র কয়েকটি যা আপনি যোগ দিতে চাইতে পারেন। আরও আছে একটি ক্রস-প্ল্যাটফর্ম I2P-ভিত্তিক ইনস্ট্যান্ট মেসেঞ্জার অ্যাপ্লিকেশন, Github-এ উপলব্ধ।
  • বেনামী এনক্রিপ্টেড ওয়েব হোস্টিং
    I2P নিজের ওয়েবসাইট I2P নেটওয়ার্কে হোস্ট করার জন্য একটি ওয়েবসার্ভার সরবরাহ করে: একটি Jetty ইনস্ট্যান্স http://127.0.0.1:7658/ শুনছে। প্রি-কনফিগার করা I2P Webserver Tunnel শুরু করার পর, আপনার সাইট অন্যদের কাছে দৃশ্যমান (কিন্তু আবিষ্কারযোগ্য নয়) হবে। আপনার সাইট সেটআপ এবং একটি .i2p ডোমেইন নিবন্ধন করার নির্দেশাবলী সাহায্য বিভাগে দেওয়া আছে।
  • I2P-এর জন্য প্লাগইন
    বিভিন্ন প্লাগইনের সরাসরি ডাউনলোড লিঙ্কের জন্য zzz-এর প্লাগইন পৃষ্ঠা পরিদর্শন করুন। আপনি যদি ডেভেলপার হন, নিজের প্লাগইন লেখার জন্য একটি ভাষা-নিরপেক্ষ ফ্রেমওয়ার্ক দেওয়া আছে।

ডেভেলপার ও অবদানকারীদের জন্য তথ্য

  • বাগ রিপোর্ট করা
    বাগ রিপোর্ট করতে, অনুগ্রহ করে github.com/I2PPlus/i2pplus/issues-এ একটি টিকিট জমা দিন। ডেভেলপার-সম্পর্কিত আলোচনার জন্য, অনুগ্রহ করে zzz-এর ডেভেলপার ফোরাম বা I2P-এর IRC নেটওয়ার্কে ডেভেলপার চ্যানেল (#i2p-dev) পরিদর্শন করুন।
  • I2P-তে ডেভেলপমেন্ট
    আপনি যদি ডেভেলপার হন, আপনি নিজের I2P অ্যাপ্লিকেশন লেখা বা I2P নেটওয়ার্কের সুবিধা নিয়ে আপনার অ্যাপ্লিকেশনের নিরাপত্তা বাড়ানো বিবেচনা করতে পারেন। UDP এবং TCP উভয় প্রোটোকলই প্রদত্ত, এবং রিয়েলটাইম স্ট্রিমিং সম্ভব। আমরা সম্পূর্ণ অ্যাক্সেস প্রদান করি Java API-তে, এবং মূল I2P লাইব্রেরিগুলো Apache Maven repository-তে হোস্ট করা হয়। ডেভেলপাররা সোর্স কোড দেখতে পারেন Github-এ (I2P) বা Github-এ (I2P+)। সোর্স থেকে বিল্ড করতে একটি Java SDK এবং Apache Ant প্রয়োজন।
  • যুক্ত হোন!
    I2P বেশিরভাগভাবে কমিউনিটি সদস্যদের অননুদানিত, স্বেচ্ছাসেবী অংশগ্রহণের মাধ্যমে ডেভেলপ ও রক্ষণাবেক্ষণ করা হয়। আপনি কীভাবে অংশ নিতে পারেন তার আরও তথ্য অফিসিয়াল ওয়েবসাইটে স্বেচ্ছাসেবক পৃষ্ঠায় পাওয়া যায়।
  • I2P+
    I2P+ সম্পর্কে আরও তথ্যের জন্য, অনুগ্রহ করে skank.i2p বা i2pplus.github.io পরিদর্শন করুন, অথবা I2P IRC নেটওয়ার্কে #saltR চ্যানেলে যোগ দিন। I2P+-এর জন্য প্যাচ স্বাগতম; অনুগ্রহ করে Gitlab-এর মাধ্যমে pull request জমা দিন।
