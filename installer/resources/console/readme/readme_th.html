• เริ่มต้นใช้งาน
    หากคุณเพิ่งเริ่มI2P+จำนวนpeerที่ใช้งานอยู่ที่แสดงในส่วนpeerบนแถบด้านข้างควรเริ่มเพิ่มขึ้นในไม่กี่นาทีข้างหน้าและคุณจะเห็นปลายทางในเครื่องชื่อไคลเอนต์ที่แบ่งปันแสดงอยู่ในส่วนอุโมงคมบริการและอาจมีไคลเอนต์และเซิร์ฟเวอร์อื่นขึ้นอยู่กับวิธีกำหนดค่าI2Pปลายทางในเครื่องเหล่านี้ให้การเชื่อมต่อไปยังบริการบนพอร์ตหลากหลายในเครือข่ายI2Pช่วยให้BitTorrentอีเมลproxyเว็บและบริการอื่นทำงานได้ฐานข้อมูลเครือข่ายของคุณจะแสดงpeerทั้งหมดที่เครื่องของคุณรู้จักในเครือข่ายคุณยังตรวจสอบการเชื่อมต่อของpeerที่มีอยู่และตรวจสอบโปรไฟล์ประสิทธิภาพของpeerและดูอุโมงคมที่ใช้งานอยู่พร้อมสถานะได้
  • การเข้าร่วมเครือข่าย
    ครั้งแรกที่คุณเริ่มI2P+อาจใช้เวลาสองสามนาทีในการเข้าร่วมเครือข่ายและค้นหาpeerเพิ่มเติมเพื่อให้การเข้าร่วมดีที่สุดดังนั้นโปรดอดทนเมื่อดาวสีเขียวปรากฏขึ้นข้างปลายทางในเครื่องของคุณในส่วนอุโมงคมบริการบนแถบด้านข้างก็จะมีหลายอย่างที่คุณทำได้กับI2Pและต่อไปนี้คือบางข้อ
  • สถานะเครือข่าย
    เมื่อI2P+มีเวลาทดสอบการเชื่อมต่อเครือข่ายของคุณแล้วตัวบ่งชี้สถานะเครือข่ายบนแถบด้านข้างในอุดมคติควรระบุ"ปกติ"หากสถานะระบุ"ติดไฟร์วอลล์"I2P+จะยังทำงานต่อแม้ประสิทธิภาพของเครือข่ายจะไม่ดีที่สุดและความสามารถในการบริจาคแบนด์วิดท์ให้เครือข่ายจะถูกจำกัดหากต้องการประสิทธิภาพที่ดีที่สุดให้พิจารณาเปิดพอร์ตภายนอกI2P+ของคุณในไฟร์วอลล์และในเราเตอร์ที่ISPจัดให้มีข้อมูลเพิ่มเติมเกี่ยวกับข้อความสถานะอยู่ในหน้าความช่วยเหลือของส่วนติดต่อผู้ใช้.
  • การติดตามสมุดที่อยู่
    เพื่อให้I2P+สามารถแปลงชื่อโฮสต์.i2pโดยอัตโนมัติต้องพึ่งพาการติดตามบริการที่ให้การแปลงDNSสำหรับโฮสต์ที่รู้จักเป็นหลักหากคุณติดตั้งI2P+แทนที่จะอัปเดตจากI2Pคุณจะมีการติดตามสมุดที่อยู่ที่กำหนดค่าไว้เพียงพอแล้วหลังการติดตั้งสมุดที่อยู่ของคุณควรเต็มไปด้วยชื่อโฮสต์ของบริการที่ใช้งานอยู่ในเครือข่ายโดยอัตโนมัติหากคุณอัปเดตจากI2Pให้ดูส่วนการติดตามสมุดที่อยู่ในคำถามที่พบบ่อยเพื่อขอความช่วยเหลือในการเพิ่มการติดตามเพิ่มเติม
  • การตั้งค่าเบราว์เซอร์
    เพื่อเลือกดูเว็บไซต์บนเครือข่ายคุณต้องตั้งค่าเบราว์เซอร์ให้ใช้proxyHTTPค่าเริ่มต้นที่กำหนดไว้บนพอร์ต4444ซึ่งยังให้outproxyที่อนุญาตให้เลือกดูเว็บไซต์บนclearnetแบบไม่ระบุตัวตนได้มีคู่มือย่อสำหรับตั้งค่าFirefoxที่หน้าการตั้งค่าในส่วนความช่วยเหลือหรือดูส่วนถัดไปเพื่อรับลิงก์ไปยังคู่มือการตั้งค่าสำหรับเบราว์เซอร์หลายตัวเมื่อคุณตั้งค่าเบราว์เซอร์และการติดตามสมุดที่อยู่แล้วnotbob.i2pเป็นเว็บไซต์ที่ดีมากสำหรับค้นพบเนื้อหาในเครือข่าย

บริการบนI2P

  • การเลือกดูอินเทอร์เน็ตแบบมองไม่เห็นและสาธารณะ
    บนI2Pคุณเข้าถึงเว็บไซต์ที่โฮสต์บนI2Pได้("eepsite")หรือเลือกดูเว็บปกติแบบไม่ระบุตัวตนผ่านproxyเว็บ(outproxy)ที่มาพร้อมI2Pตั้งค่าเบราว์เซอร์ของคุณให้ใช้proxyHTTPที่127.0.0.1พอร์ต4444จากนั้นเลือกดูไปยังเว็บไซต์บริการซ่อนตัวหรือที่อยู่ปกติที่ไม่ได้เข้ารหัสด้วยhttp://หากต้องการปิดใช้งานหรือเปลี่ยนการเข้าถึงoutproxyของอินเทอร์เน็ตปกติให้ลบหรือแก้ไขรายการoutproxyสำหรับfalse.i2pหรือpurokishi.i2pในส่วนoutproxyในหน้าแก้ไขของอุโมงคมไคลเอนต์proxyHTTPในตัวจัดการอุโมงคม.
  • อีเมลแบบไม่ระบุตัวตน
    ระบบอีเมลบนI2PของPostmanเข้าถึงได้ผ่านไคลเอนต์อีเมลในตัวของI2P(Susimail)หรือไคลเอนต์อีเมลมาตรฐานใดก็ได้เกตเวย์อีเมลช่วยให้รับอีเมลจากที่อยู่อินเทอร์เน็ตปกติได้ที่อยู่@mail.i2pของคุณก็ติดต่อผ่าน@i2pmail.orgได้หากต้องการบัญชีให้ไปที่hq.postman.i2p.
  • การถ่ายโอนไฟล์แบบไม่ระบุตัวตน
    I2PSnarkถูกรวมอยู่ในI2Pและนำเสนอการถ่ายโอนBitTorrentแบบไม่ระบุตัวตนและเข้ารหัสทางเลือกอื่นคือBiglyBT(ต่อยอดจากAzureus/Vuze)ซึ่งเป็นไคลเอนต์BitTorrentที่รองรับtorrentผ่านI2PและXDซึ่งเป็นไคลเอนต์BitTorrentเฉพาะI2Pที่เขียนด้วยGoบริการเพิ่มเติมรวมถึงการโฮสต์ไฟล์บนเบราว์เซอร์เช่นcake.i2pและfs.i2p.
  • แชทแบบไม่ระบุตัวตน
    เปิดไคลเอนต์IRCของคุณ(ตัวอย่างเช่นHexChat)แล้วเชื่อมต่อไปยังเซิร์ฟเวอร์ที่127.0.0.1พอร์ต6668คุณไม่จำเป็นต้องตั้งค่าproxyในไคลเอนต์IRCเพราะI2Pให้อุโมงคมIRCในเครื่องแก่คุณ(ตั้งค่าในไคลเอนต์IRCเป็นเซิร์ฟเวอร์IRCหรือโฮสต์ระยะไกล)เมื่อเข้าไปแล้ว#saltrและ#i2p-devเป็นเพียงบางช่องทางที่คุณสามารถเข้าร่วมได้ยังมีแอปแชททันทีข้ามแพลตฟอร์มที่ใช้I2Pซึ่งมีอยู่ที่Github.
  • โฮสต์เว็บแบบไม่ระบุตัวตนและเข้ารหัส
    I2Pมาพร้อมเว็บเซิร์ฟเวอร์สำหรับโฮสต์เว็บไซต์ของคุณเองบนเครือข่ายI2P:อินสแตนซ์ของJettyที่ฟังอยู่ที่http://127.0.0.1:7658/หลังจากเริ่มอุโมงคมของเว็บเซิร์ฟเวอร์I2Pที่ตั้งค่าไว้ล่วงหน้าเว็บไซต์ของคุณจะมองเห็นได้(แต่ค้นพบไม่ได้)โดยผู้อื่นคำแนะนำในการตั้งค่าเว็บไซต์และจดทะเบียนโดเมน.i2pอยู่ในส่วนความช่วยเหลือ.
  • ปลั๊กอินสำหรับI2P
    ไปที่หน้าปลั๊กอินของzzzเพื่อดาวน์โหลดปลั๊กอินได้หลายตัวโดยตรงหากคุณเป็นผู้พัฒนาจะมีเฟรมเวิร์กที่ไม่ขึ้นกับภาษาสำหรับเขียนปลั๊กอินของคุณเอง.

ข้อมูลสำหรับผู้พัฒนาและผู้ร่วมพัฒนา

  • รายงานข้อผิดพลาด
    หากต้องการรายงานข้อผิดพลาดโปรดเปิดticketที่github.com/I2PPlus/i2pplus/issuesหากต้องการพูดคุยเกี่ยวข้องกับผู้พัฒนาโปรดไปที่ฟอรัมผู้พัฒนาของzzzหรือช่องทางผู้พัฒนา(#i2p-dev)บนเครือข่ายIRCของI2P.
  • การพัฒนาบนI2P
    หากคุณเป็นผู้พัฒนาคุณอาจพิจารณาเขียนแอปพลิเคชันI2Pของคุณเองหรือปรับปรุงความปลอดภัยของแอปพลิเคชันโดยใช้ประโยชน์จากเครือข่ายI2Pทั้งโปรโตคอลUDPและTCPได้รับการจัดเตรียมไว้และสามารถทำการส่งข้อมูลแบบเรียลไทม์ได้เรายังให้การเข้าถึงAPIของJavaได้อย่างเต็มที่และไลบรารีหลักของI2Pถูกโฮสต์ไว้ในที่เก็บApache Mavenผู้พัฒนาสามารถเลือกดูซอร์สโค้ดได้ที่Github(I2P)หรือGithub(I2P+)และตรวจสอบสถานะปัจจุบันของบิลด์ผ่านแพลตฟอร์มการบูรณาการต่อเนื่องTravis(I2P)หรือผ่านGitlab(I2P+)ต้องมีJava SDKและApache Antเพื่อบิลด์จากซอร์สโค้ด.
  • เข้าร่วม!
    I2Pได้รับการพัฒนาและดูแลโดยหลักจากการมีส่วนร่วมอย่างอาสาสมัครและไม่ได้รับเงินทุนของสมาชิกในชุมชนข้อมูลเพิ่มเติมเกี่ยวกับวิธีเข้าร่วมอยู่ในหน้าอาสาสมัครบนเว็บไซต์ทางการ.
  • I2P+
    หากต้องการข้อมูลเพิ่มเติมเกี่ยวกับI2P+โปรดไปที่skank.i2pหรือi2pplus.github.ioหรือเข้าร่วมช่องทาง#saltRบนเครือข่ายIRCของI2Pการแก้ไขสำหรับI2P+ได้รับการต้อนรับโปรดส่งคำขอดึงผ่านGitlab.
