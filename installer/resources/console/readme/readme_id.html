• Memulai
    Jika Anda baru saja memulai I2P+, jumlah Peer Aktif yang ditunjukkan di bagian Peers pada bilah sisi akan mulai bertambah dalam beberapa menit ke depan, dan Anda juga akan melihat Tujuan Lokal bernama Shared Clients terdaftar di bagian Tunnel Layanan, serta mungkin klien dan server lain tergantung pada cara I2P dikonfigurasi. Tujuan Lokal ini menyediakan koneksi ke layanan pada port yang berbeda di jaringan I2P, sehingga memungkinkan BitTorrent, email, web proxy, dan layanan lainnya berfungsi. Basis Data Jaringan Anda menunjukkan semua peer yang diketahui secara lokal di jaringan. Anda juga dapat memantau koneksi peer yang sudah ada, meninjau profil kinerja peer, dan melihat tunnel aktif beserta statusnya.
  • Integrasi Jaringan
    Saat pertama kali Anda memulai I2P+, mungkin diperlukan beberapa menit untuk melakukan bootstrap (mengintegrasikan) Anda ke dalam jaringan dan menemukan peer tambahan guna menyempurnakan integrasi Anda, jadi mohon sabar. Setelah bintang hijau muncul di sebelah Tujuan Lokal Anda di bagian Tunnel Layanan pada bilah sisi, ada berbagai hal yang dapat Anda lakukan dengan I2P, dan di bawah ini kami memperkenalkan beberapa di antaranya kepada Anda.
  • Status Jaringan
    Setelah I2P+ diberi waktu untuk menguji konektivitas jaringan Anda, indikator Status Jaringan pada bilah sisi idealnya akan menampilkan "OK". Jika status menampilkan "Firewalled", I2P+ tetap akan berfungsi meskipun kinerja jaringan tidak akan optimal, dan kemampuan Anda untuk menyumbangkan bandwidth ke jaringan akan terhambat. Untuk kinerja optimal, mohon pertimbangkan untuk membuka port eksternal I2P+ Anda pada firewall dan router yang disediakan oleh ISP Anda. Informasi lebih lanjut tentang pesan status tersebut tersedia di halaman bantuan Antarmuka Pengguna.
  • Langganan Buku Alamat
    Agar I2P+ dapat menyelesaikan nama host .i2p secara otomatis, I2P+ terutama mengandalkan langganan ke layanan yang menyediakan penerjemahan DNS untuk host yang dikenal. Jika Anda memasang I2P+ alih-alih melakukan peningkatan dari I2P, Anda sudah akan memiliki cukup banyak langganan buku alamat yang terkonfigurasi; setelah pemasangan, buku alamat Anda seharusnya sudah terisi dengan nama host untuk layanan aktif di jaringan tanpa perlu intervensi. Jika Anda telah melakukan peningkatan dari I2P, periksa bagian langganan buku alamat di FAQ untuk bantuan menambahkan langganan tambahan.
  • Konfigurasi Peramban
    Untuk menjelajahi situs web di jaringan, Anda perlu mengonfigurasi peramban Anda agar menggunakan HTTP proxy bawaan yang dikonfigurasi pada port 4444, yang juga menyediakan outproxy sehingga memungkinkan penjelajahan anonim atas situs di clearnet. Panduan singkat untuk mengonfigurasi Firefox disediakan pada halaman Konfigurasi di bagian bantuan, atau lihat bagian di bawah ini untuk tautan ke panduan pengaturan multibrowser. Setelah Anda mengonfigurasi peramban dan langganan buku alamat Anda, notbob.i2p adalah situs yang bagus untuk menemukan konten di jaringan.

Layanan di I2P

  • Internet Tak Kasat Mata & Penjelajahan Web Publik
    Di I2P Anda dapat mengakses situs web yang di-host di I2P ("eepsite") atau menjelajahi web biasa secara anonim melalui web proxy (outproxy) bawaan I2P. Konfigurasikan peramban Anda agar menggunakan HTTP proxy di 127.0.0.1 port 4444, lalu jelajahi sebuah situs web layanan tersembunyi atau alamat http:// biasa yang tidak terenkripsi. Untuk menonaktifkan atau mengubah akses outproxy ke internet biasa, hapus atau ubah entri outproxy untuk false.i2p atau purokishi.i2p di bagian Outproxies pada halaman edit tunnel klien HTTP Proxy di Tunnel Manager.
  • Email Anonim
    Sistem email berbasis I2P dari Postman dapat diakses melalui klien email bawaan I2P (Susimail) atau klien email standar apa pun. Gateway email memungkinkan email diterima dari alamat internet biasa; alamat @mail.i2p Anda juga dapat dihubungi melalui @i2pmail.org. Untuk memperoleh akun, kunjungi hq.postman.i2p.
  • Transfer File Anonim
    I2PSnark terintegrasi ke dalam I2P, menyediakan transfer BitTorrent yang anonim dan terenkripsi. Sebagai alternatif, ada BiglyBT (penerus Azureus/Vuze), yaitu klien BitTorrent yang mendukung torrent melalui I2P, dan XD, klien BitTorrent khusus I2P yang ditulis dengan go. Layanan tambahan mencakup hosting file berbasis peramban seperti cake.i2p dan fs.i2p.
  • Chat Anonim
    Mulai klien IRC Anda (misalnya HexChat) dan sambungkan ke server di 127.0.0.1 port 6668. Anda tidak perlu mengonfigurasi proxy di klien IRC Anda; I2P menyediakan tunnel IRC lokal (dikonfigurasi di klien IRC Anda sebagai server IRC atau remote host). Setelah tiba di sana, #saltr dan #i2p-dev hanyalah beberapa dari channel yang tersedia yang mungkin ingin Anda gabung. Ada juga aplikasi pesan instan lintas platform berbasis I2P, tersedia di Github.
  • Hosting Web Anonim Terenkripsi
    I2P dilengkapi dengan webserver untuk meng-hosting situs web Anda sendiri di jaringan I2P: sebuah instans Jetty yang mendengarkan di http://127.0.0.1:7658/. Setelah memulai Tunnel Webserver I2P yang telah dikonfigurasi sebelumnya, situs Anda akan terlihat (tapi tidak dapat ditemukan) oleh pihak lain. Petunjuk untuk menyiapkan situs Anda dan mendaftarkan domain .i2p disediakan di bagian bantuan.
  • Plugin untuk I2P
    Kunjungi halaman plugin zzz untuk tautan unduhan langsung beberapa plugin. Jika Anda adalah pengembang, disediakan framework yang independen terhadap bahasa untuk menulis plugin Anda sendiri.

Informasi untuk Pengembang & Kontributor

  • Melaporkan Bug
    Untuk melaporkan bug, silakan buat tiket di github.com/I2PPlus/i2pplus/issues. Untuk diskusi terkait pengembang, silakan kunjungi forum pengembang zzz atau channel pengembang (#i2p-dev) di jaringan IRC I2P.
  • Mengembangkan di I2P
    Jika Anda adalah pengembang, Anda mungkin mempertimbangkan untuk menulis aplikasi I2P Anda sendiri atau meningkatkan keamanan aplikasi Anda dengan memanfaatkan jaringan I2P. Kedua protokol UDP dan TCP telah disediakan, dan streaming waktu nyata juga memungkinkan. Kami juga menyediakan akses penuh ke Java API, dan pustaka inti I2P di-host di repositori Apache Maven. Pengembang dapat menjelajahi kode sumber di Github (I2P) atau Github (I2P+). Java SDK dan Apache Ant diperlukan untuk membangun dari kode sumber.
  • Ikut Berlibat!
    I2P dikembangkan dan dipelihara terutama melalui partisipasi sukarela tanpa pendanaan dari anggota komunitas. Informasi lebih lanjut tentang cara Anda berpartisipasi tersedia di halaman sukarelawan pada situs web resmi.
  • I2P+
    Untuk informasi lebih lanjut tentang I2P+, silakan kunjungi skank.i2p atau i2pplus.github.io, atau bergabunglah dengan channel #saltR di jaringan IRC I2P. Kontribusi patch untuk I2P+ kami terima dengan senang; silakan kirim pull request melalui Gitlab.
