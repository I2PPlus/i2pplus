• Pagsisimula
    Kung pinagsimula mo lang ang I2P+, dapat magsimulang lumago ang bilang ng Aktibong Peer na ipinapakita sa Peer na bahagi sa sidebar, at makikita mo rin ang Local Destination na tinatawag na Shared Clients na nakalista sa Service Tunnel na bahagi, at posibleng iba pang client at server depende sa pagkakaayos ng I2P. Ang mga Local Destination na ito ay nagbibigay ng koneksyon sa mga serbisyo sa iba't ibang port sa network ng I2P, na nagbibigay-daan sa BitTorrent, email, web proxy, at iba pang serbisyo na gumagana. Ang iyong Network Database ay nagpapakita ng lahat ng peer na kilala lokal sa network. Maaari mo ring bantayan ang umiiral na koneksyon ng peer, suriin ang profile ng performance ng peer, at tingnan ang aktibong tunnel at ang kanilang katayuan.
  • Pagsasama sa Network
    Sa unang pagpapaganad ng I2P+, maaaring tumagal ng ilang minuto bago ka masimulan (magkasama) sa network at makahanap ng karagdagang peer upang ma-optimize ang pagsasama mo, kaya magpakinta lamang. Kapag mayroon nang berdeng bituin sa tabi ng iyong Local Destination sa Service Tunnel na bahagi ng sidebar, may iba't ibang bagay na magagawa mo sa I2P, at ilan sa mga ito ang ipinapakita namin sa ibaba.
  • Katayuan ng Network
    Kapag nabigyan na ng panahon ang I2P+ na subukan ang iyong konektibidad sa network, dapat ideklara ng indicator ng Network Status sa sidebar na "OK". Kung ang katayuan ay "Firewalled", gagana pa rin ang I2P+ bagaman hindi magiging pinakamainam ang performance ng network, at maaapektuhan ang iyong kakayahang magbigay ng bandwidth sa network. Para sa pinakamainam na performance, isaalang-alang ang pagbubukas ng iyong external I2P+ port sa iyong firewall at sa router na ibinigay ng iyong ISP. May higit pang impormasyon tungkol sa mga mensahe ng katayuan sa pahina ng tulong para sa User Interface.
  • Subscription ng Address Book
    Para awtomatikong ma-resolve ng I2P+ ang mga .i2p hostname, umaasa ito lalo sa mga subscription sa mga serbisyo na nagbibigay ng DNS translation para sa mga kilalang host. Kung nag-install ka ng I2P+ sa halip na mag-upgrade mula sa I2P, mayroon ka nang sapat na subscription ng address book na naka-configure; pagkatapos ng installation, dapat mapuno ang iyong address book ng hostname para sa mga aktibong serbisyo sa network nang walang tulong ng sinuman. Kung nag-upgrade ka mula sa I2P, tingnan ang bahagi ng subscription ng address book sa FAQ para sa tulong sa pagdaragdag ng karagdagang subscription.
  • Pag-aayos ng Browser
    Upang mag-browse ng website sa network, kailangan mong i-configure ang iyong browser na gumamit ng default na HTTP proxy na naka-configure sa port 4444, na nagbibigay din ng outproxy na nagpapahintulot sa anonymous na pag-browse ng clearnet site. May mini-guide sa pag-aayos ng Firefox sa Configuration page sa bahagi ng tulong, o tingnan ang bahagi sa ibaba para sa link sa gabay na multi-browser. Kapag n-configure mo na ang iyong browser at subscription ng address book, ang notbob.i2p ay isang magandang site para makita ang nilalaman sa network.

Mga Serbisyo sa I2P

  • Palabas na Internet at Pambublikong Pag-browse ng Web
    Sa I2P, maaari mong i-access ang mga website na naka-host sa I2P ("eepsite") o mag-browse ng normal na web nang anonymous sa pamamagitan ng built-in na web proxy (outproxy) ng I2P. I-configure ang iyong browser upang gumamit ng HTTP proxy sa 127.0.0.1 port 4444, pagkatapos ay mag-browse sa website ng nakatagong serbisyo o sa normal na hindi naka-encrypt na http:// na address. Upang i-disable o baguhin ang outproxy access sa normal na internet, alisin o baguhin ang outproxy entry para sa false.i2p o purokishi.i2p sa Outproxies na bahagi sa pahina ng edit ng HTTP Proxy client tunnel sa Tunnel Manager.
  • Anonymous na Email
    Ang mail system ng Postman na nakabatay sa I2P ay maaaring i-access alinman sa pamamagitan ng built-in na mail client ng I2P (SusiMail) o kahit anong karaniwang mail client. May mail gateway na nagpapahintulot na matanggap ang email mula sa normal na internet address; maaari ding makausap ang iyong @mail.i2p address sa pamamagitan ng @i2pmail.org. Para sa account, bisitahin ang hq.postman.i2p.
  • Anonymous na Paglipat ng File
    Ang I2PSnark ay naka-integrate sa I2P, at nagbibigay ng anonymous at naka-encrypt na BitTorrent transfer. Alternatibo, may BiglyBT (ang kapalit ng Azureus/Vuze), isang BitTorrent client na sumusuporta sa torrent sa I2P, at XD, isang BitTorrent client para lamang sa I2P na nakasulat sa go. Kasama sa karagdagang serbisyo ang browser-based na file hosting tulad ng cake.i2p at fs.i2p.
  • Anonymous na Chat
    Simulan ang iyong IRC client (halimbawa, HexChat) at kumonekta sa server sa 127.0.0.1 port 6668. Hindi mo kailangang mag-configure ng proxy sa iyong IRC client; nagbibigay ang I2P sa iyo ng lokal na IRC tunnel (na naka-configure sa iyong IRC client bilang IRC server o remote host). Kapag nandoon ka na, ang #saltr at #i2p-dev ay ilan lamang sa mga available na channel na maaari mong salihan. Mayroon ding cross-platform na instant messenger application na nakabatay sa I2P, na available sa Github.
  • Anonymous at Naka-encrypt na Web Hosting
    May kasamang webserver ang I2P para i-host ang iyong sariling website sa network ng I2P: isang Jetty instance na nakikinig sa http://127.0.0.1:7658/. Pagkatapos simulan ang naka-configure nang I2P Webserver Tunnel, makikita ng iba ang iyong site (bagaman hindi matatagpuan). Nasa bahagi ng tulong ang mga tagubilin sa pag-aayos ng iyong site at pagpaparehistro ng .i2p domain.
  • Mga Plugin para sa I2P
    Bisitahin ang plugins page ng zzz para sa mga link upang direktang mag-download ng ilang plugin. Kung developer ka, may framework na hindi nakatali sa isang wika para sa paggawa ng sarili mong plugin.

Impormasyon para sa Mga Developer at Kontributor

  • Pag-uulat ng Mga Bug
    Upang mag-ulat ng bug, mangyaring mag-file ng ticket sa github.com/I2PPlus/i2pplus/issues. Para sa mga usapang may kinalaman sa developer, mangyaring bisitahin ang developer forum ng zzz o ang developer channel (#i2p-dev) sa IRC network ng I2P.
  • Pag-unlad sa I2P
    Kung developer ka, maaaring isaalang-alang ang pagsulat ng sarili mong I2P application o pagbutas ng seguridad ng iyong application sa pamamagitan ng network ng I2P. Ang UDP at TCP na protocol ay naka-provision, at posible din ang streaming sa totoong panahon. Nagbibigay din kami ng buong access sa Java API, at naka-host ang mga pangunahing library ng I2P sa Apache Maven repository. Maaaring tingnan ng mga developer ang source sa Github (I2P) o sa Github (I2P+), at bantayan ang kasalukuyang katayuan ng build sa pamamagitan ng platforma ng tuluy-tuloy na integrasyon Travis (I2P) o sa pamamagitan ng Gitlab (I2P+). Kailangan ang Java SDK at Apache Ant upang mag-build mula sa source.
  • Makilahok!
    Ang I2P ay binubuo at pinananatili sa halos buong bahagi sa pamamagitan ng boluntaryong pakikilahok ng mga miyembro ng komunidad na walang pinansinang pondo. May higit pang impormasyon tungkol sa kung paano ka makakilahok sa volunteers page sa opisyal na website.
  • I2P+
    Para sa higit pang impormasyon tungkol sa I2P+, mangyaring bisitahin ang skank.i2p o ang i2pplus.github.io, o sumali sa channel na #saltR sa IRC network ng I2P. Maligayang tumanggap ng mga patch para sa I2P+; mangyaring isumite ang mga pull request sa pamamagitan ng Gitlab.
