If you left Windows Service ticked on the previous page, the I2P+ service is installed now and should be running automatically. To manage the service startup properties, run services.msc from the start menu or a command line, and then adjust the I2P+ service accordingly, or configure from within the Router Console.

If you left it unticked, I2P+ runs as an ordinary application, started from the i2p.exe file in your application folder, usually found at C:\Program Files\i2p\. To run it as a service after all, open a command prompt as Administrator and run service.ps1 -Action Install from that folder.

Shortcuts are provided to stop and start the service, though in normal operation you should use the console to stop the service as this will allow the router to honor its networking obligations before shutting down or restarting.
