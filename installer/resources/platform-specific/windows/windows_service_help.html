If you left Windows Service ticked on the previous page, the I2P+ service is installed now and should be running automatically. To manage the service startup properties, run services.msc from the start menu or a command line, and then adjust the I2P+ service accordingly, or configure from within the Router Console.

If you left it unticked, I2P+ is not registered as a service. Run portable.ps1 from your application folder, usually found at C:\Program Files\i2p\, and the router runs in that window with its configuration in a configuration folder inside the application folder. That is a portable installation: the whole folder, configuration included, can sit on a USB stick and travel with you. Pass it a folder of your own to keep the configuration elsewhere, as in portable.ps1 -ConfigDir E:\i2p-profile.

To run as a service after all, open a command prompt as Administrator and run service.ps1 -Action Install from the application folder.

Shortcuts are provided to stop and start the service, though in normal operation you should use the console to stop the service as this will allow the router to honor its networking obligations before shutting down or restarting.
