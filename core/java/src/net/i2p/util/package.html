General utility classes shared across the core libraries and the router.

  • Logging (Log, LogManager, LogWriter outputs)
  • HTTP fetches through the proxy (EepGet)
  • String and encoding helpers (see also {@link net.i2p.data.DataHelper})
  • Collection and map helpers
  • File and I/O helpers
  • Thread and executor helpers
  • Network address utilities
  • Random sources (RandomSource, FortunaRandomSource)
  • Native BigInteger support via the jbigi library
  • System version and memory checks

Classes here may be changed or moved without notice.
