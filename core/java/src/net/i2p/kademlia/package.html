Generic Kademlia distributed hash table implementation supporting multiple hash algorithms (SHA1, SHA256, etc.), with:

  • KBucket implementation for peer storage
  • KBucketSet for managing multiple buckets
  • Generic key support for different hash lengths
  • Kademlia routing table management
  • Trimmer strategies deciding which peer to evict from a full bucket

Major rewrite of KBucket, KBucketSet, and KBucketImpl from {@link net.i2p.router.networkdb.kademlia}, now generic to support SHA1, SHA256, or other key lengths.
