The client-facing surface of the I2CP library: {@code I2PClientTest} for the client's session and destination handling, gathered by {@code I2PClientTestSuite}, and {@code SendMessageOptionsTest} for the per-message options (reliability, priority, tunnel limits) a sender may set.

Run by ant test in core/java. The tests that need a live router are named {@code *IT} and live in {@code net.i2p.client.impl}, not here.
