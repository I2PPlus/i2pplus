The session implementation's decisions, tested without a router: the lease-set request path ({@code RequestLeaseSetHandlerTest}, {@code RequestLeaseSetSignGuardTest} for the signature guard), the send queue's timeout handling ({@code SendQueueTimeoutTest}), and what a session does when a tunnel build times out ({@code TunnelBuildTimeoutTest}).
