The entry points of the core suite rather than tests of a class: {@link net.i2p.AllCoreTests} aggregates the per-package suites, and {@link net.i2p.TestContext} hands a test an {@code I2PAppContext} with the services it needs, without a router.

ant test in core/java runs every *Test.java by name pattern, so these suites are one way to run the group, not the only way.
