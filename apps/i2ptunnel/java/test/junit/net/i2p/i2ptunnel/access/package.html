The tunnel access filter's rule engine: the sliding-window counter's threshold-breach detection, the threshold equality that gates a reload of the access list, the definition parser's case-insensitive rule words, the destination tracker that pairs a counter with a threshold, the recorder file's read cache, and the bounded queue in front of the disk writer every filtered tunnel shares - exercised on the real filesystem with temp files, as the filter writes it.
