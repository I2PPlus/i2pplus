Tests for the filters the webapps declare in their web.xml: {@code OriginFilter}, the cross-origin POST refusal the address book reaches through a filter mapping, and {@code XSSRequestWrapper}, the parameter scrubber the console and all three webapps wrap every request in.

The decision rules themselves live with the classes they guard — the Origin rule is pinned beside it in the servlet.util suite — so what is covered here is the wiring: which methods a filter guards, which requests it lets through untouched, and that a refusal stops the chain instead of reporting a refusal and carrying out the change anyway. No Jetty, socket or webapp is started; the requests are mocked. {@code ant test} in apps/jetty runs each {@code *Test.java}.
