The Jetty classes we carry a patch for, compiled into jetty-util-patch.jar and put on the classpath ahead of the stock jetty-util.jar. Only what has to change is here.

{@code JavaVersion} is backported from Jetty 9.4.34: the 9.3.x parser cannot read the version string of a modern JVM, and the router console does not start without it. Jetty does not fix this on the 9.3.x branch.

See also: jetty.project, from which these files are taken and patched.
