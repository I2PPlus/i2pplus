The console-facing layer of I2PSnark, in net.i2p.i2psnark: the browser API the console pages call, the escaping and validation the app applies to user input, the hex helpers of {@link net.i2p.i2psnark.I2PSnarkUtil} - the base64 and hex forms of an info hash - and the inclusive byte range a partial piece download is described by. Run by ant test in apps/i2psnark/java.
