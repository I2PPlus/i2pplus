I2P version of the Snark BitTorrent client, enhanced for I2P: peers are I2P destinations, torrents can be served anonymously as hidden services, and metadata carries I2P-specific comment fields. The main entry points are SnarkManager and the web interface in {@link org.klomp.snark.web}.

See also: BEP 3 • BEP 5 (DHT) • BEP 6 (FAST) • BEP 10 (extension protocol) • BEP 15 (UDP tracker) • BEP 47 (padding) • BEP 54 (dont_have).
