The path the console login filter decides on. The filter used to match public-page prefixes against the request target as the client sent it, while the container decodes that path and resolves {@code .} and {@code ..} before it maps the request, so a traversal segment written after a public prefix passed the filter and named a protected page. The canonicaliser and the prefix match are plain statics or a no-arg instance, so they are tested without a running router or a servlet container. Run by ant test in apps/routerconsole.
