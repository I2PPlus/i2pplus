The address book's pure helpers: {@code HostTxtParser} for the hosts.txt line format - the subscription URL, the label, the flags, and the lines it refuses; {@code HostCheckerBridgeEscapeTest} for the display escaping the subscription page renders a host name through; and {@code HostCheckerProbeDecisionTest} for what the host checker decides from its configuration - whether the periodic check runs, the proxy the HEAD fallback goes through, and how many names one cycle probes. Run by ant test at the top level.
