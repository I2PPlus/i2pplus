The address book's pure helpers: {@code HostTxtParser} for the hosts.txt line format - the subscription URL, the label, the flags, and the lines it refuses; {@code HostCheckerBridgeEscapeTest} for the display escaping the subscription page renders a host name through; and {@code HostCheckerProbeDecisionTest} for what the host checker decides from its configuration - whether the periodic check runs, the proxy the HEAD fallback goes through, and how many names one cycle probes. {@code SubscriptionMetadataTest} for the subscription metadata round trip - the etags, last-modified and last-fetched files are keyed by subscription URL, and a URL of any case has to find its own entry. Run by ant test at the top level.
