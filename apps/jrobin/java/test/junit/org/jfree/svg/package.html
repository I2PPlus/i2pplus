The SVG writer the console's graphs are rendered through, patched for our themes: the CSS colour parsing the graph theme variables go through; the retag rule for the axis container lines; the line-run grouping that collapses adjacent <line> elements into a <g>; and the relative coordinate encoding of emitted path data, where a cubic's three coordinate pairs are all relative to the same point. Run by ant test in apps/jrobin/java.
