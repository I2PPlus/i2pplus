The SAM bridge's decisions, tested without a running router: connection ownership and the {@code AUTH} authorization rule - which client may claim a destination, and who is refused ({@code ClientOwnershipTest}); the hand-off that keeps a handler's teardown off the pool's selector thread ({@code SAMHandlerPoolTeardownTest}); the session debug table the console renders ({@code SAMDebugTableTest}); and the standalone parsing in {@code SAMUtils} - the master-key and destination forms, and the destination-string grammar. Also the hello gate at the head of a connection: the first line must be {@code HELLO VERSION}, or a browser posting to the SAM port has a session and its following lines run as SAM commands ({@code SAMHelloGateTest}). Run by ant test in apps/sam/java.
