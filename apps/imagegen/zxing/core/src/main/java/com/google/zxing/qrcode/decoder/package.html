The QR code structures the encoder writes and a reader would read: {@link com.google.zxing.qrcode.decoder.ErrorCorrectionLevel}, {@link com.google.zxing.qrcode.decoder.Mode}, {@link com.google.zxing.qrcode.decoder.Version} and {@link com.google.zxing.qrcode.decoder.FormatInformation}. This subset has no reader, detector or bit-source classes; the parent package uses these for writing only.

See also: zxing, from which this subset is taken.
